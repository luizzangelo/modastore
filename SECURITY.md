# Política de segurança

Não abra uma issue pública para vulnerabilidades. Envie um relato privado ao mantenedor do repositório com descrição, impacto e passos de reprodução. Não inclua credenciais reais.

O projeto nunca deve armazenar senha do banco, chave secreta ou `service_role`. Caso uma credencial seja publicada por engano, revogue-a imediatamente antes de removê-la do histórico.
